# 公開用整理と実行記録

元の4粒子・32粒子のコード・結果は保全した。公開版はそのコピーで、出力を追跡済みresults/へ上書きせずruns/へ分離する。run.pyの数値アルゴリズム・seed・学習設定は変更していない。

公開用変更は、上流コードの参照をvendor/neuralCTまたはNEURALCT_UPSTREAMへ変更、出力をruns/harmonic4・runs/harmonic32またはNEURALCT_RUN_DIRへ変更、既存4粒子結果の上書き防止、ライセンス・出典のヘッダ追加。依存は元の専用venvのpip freezeを固定した。

上流コードはcloneして固定commitを検証する。venv、上流のGit管理情報、checkpoint、標本配列は追跡しない。既存のローカルcheckpointは保全している。重みを配布しないため、新規利用者がevaluateだけを実行する場合も先に学習する必要がある。4粒子の学習はMacで約3秒、32粒子は約128秒だったが、他の環境での所要時間を保証しない。

結果ファイルは元の記録からコピーし、数値の良い実行だけを選び直していない。計測時間は元のMacでの実測であり、公開版の新しい学習時間ではない。

docs/comparison_audit.mdは初回4粒子実験の時点の監査文書。そこにある今回／未実行／コード行番号はその時点の意味であり、32粒子の最新状況はREADMEを参照。個人絶対パスを除去し、ファイルリンクを公開配置に合わせた。監査のローカル元文書は変更していない。

公開前のチェック項目と実施結果はdocs/VALIDATION.mdに記録する。GitHub Actionsによる再学習CIは設けない。これによりクラウド計算を新たに起動せず、実測がMacローカルで行われたことを明確にする。

公開CSVの改行だけをLFへ統一した。数値・行数は変更していない。
